# Навігатор «Магія ліній»

Стартовий Telegram Mini App на Node.js, Express і PostgreSQL. У базі створюються 5 категорій та 19 гілок; посилання на теми можна поступово додати в адмін-панелі.

## Локальний запуск

1. Встановіть Node.js 20 або новішу версію та створіть базу PostgreSQL у Neon.
2. Скопіюйте `.env.example` у `.env`, заповніть `DATABASE_URL`, токен нового бота та `ADMIN_IDS` (числові Telegram ID адміністраторів).
3. Виконайте `npm install`, потім `npm run db:setup` і `npm start`.
4. Для Telegram Web App потрібна публічна HTTPS-адреса. Локальний HTTP запуск придатний лише для перегляду в браузері.

## Розгортання на Render

Створіть Web Service із цією папкою як коренем проєкту. Build command: `npm install`; Start command: `npm start`. Додайте `DATABASE_URL`, `BOT_TOKEN`, `WEBAPP_URL` і `ADMIN_IDS` у змінні середовища. Після першого створення бази запустіть `npm run db:setup` один раз. У BotFather налаштуйте Mini App на HTTPS-URL сервісу; після розгортання виконайте `npm run bot:menu`, щоб встановити кнопку меню.

## Посилання на гілки

`telegram_url` у таблиці `branches` може залишатися порожнім, поки адміністратор не скопіює прямі посилання на теми. Картка без URL показується неактивною. Коли посилання додано, картка відкриває відповідну тему Telegram.

## Адмін-панель

Відкрийте `/admin.html` усередині Telegram Mini App. Адміністратори, чиї числові Telegram ID внесені в `ADMIN_IDS`, можуть додавати або змінювати посилання `t.me` та описи гілок. Сервер перевіряє підпис Telegram Web App initData перед доступом.

Не зберігайте `.env` у репозиторії та не надсилайте токен бота в чат.
